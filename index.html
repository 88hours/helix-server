How it works

Four agents. One approval.

Each agent hands off to the next automatically. You only step in when the fix is ready.

01

Crash Handler

Receives Sentry or Rollbar webhooks, classifies severity, detects the application language, and produces a structured crash report.

02

QA Agent

Deduplicates against open GitHub Issues. If it's a known bug, skips the pipeline and notifies Slack. Otherwise, clones the repo and generates a failing test asserting correct behaviour.

03

Dev Agent

Runs a full TDD loop: clones the repo, runs the failing test, writes the minimum fix, and verifies the full suite. Retries up to 3 times. On success, opens a pull request.

04

Notifier Agent

Posts an Approve / Reject message to Slack when a PR is ready. Sends escalation alerts with full context if the Dev Agent exhausts all retries.

05 — Human approval

You approve or reject in Slack

Click Approve & Merge to merge the PR automatically, or Reject to leave it open for manual review. Nothing reaches production without your sign-off.

Built to last

Reliable by design

Every architectural decision in Helix Cloud prioritises correctness, safety, and full observability.

01

Secure by default

All webhook payloads are HMAC-verified. Per-project credentials are scoped and stored securely. No code merges without explicit human approval in Slack.

02

Correct, not just fast

The QA Agent writes tests that assert correct behaviour — not just that the crash disappears. The Dev Agent runs a full TDD loop with up to 3 retries before escalating.

03

Full observability

End-to-end distributed tracing via OpenTelemetry. Every LLM call traced in LangSmith with token usage and latency. Automated CI evals fail if any agent scores below 80%.

Helix Cloud

Built for self-sustaining production systems

Not a toy. Every decision was made so your codebase can detect, fix, and recover from bugs on its own.

Correct-behaviour tests

The QA Agent writes tests that assert what the function should return, not that the crash occurs. Validated and retried if wrong.

Multi-language

Python, JavaScript, TypeScript, Ruby, Java, Kotlin, and Go. Stack trace parsing, test generation, and fix commands are all language-aware.

TDD loop with retries

The Dev Agent runs the failing test, writes a fix, runs the full suite, and retries up to 3 times. Each retry learns from previous failed attempts.

Human approval gate

Every fix requires a human to approve via Slack before the PR is merged. Approve & Merge or Reject — nothing reaches production automatically.

Smart deduplication

Checks open GitHub Issues before running the pipeline. If the bug is known, skips straight to a Slack notification and prompts you to approve any pending PR.

Project dashboard

React dashboard with Auth0 login. Add projects, watch the pipeline run live with SSE streaming, and review crash reports, test cases, and PRs — all in one place.

Per-project credentials

Each project stores its own Anthropic key, Sentry secret, Rollbar token, Slack channel, and email settings. Every project gets a dedicated webhook URL scoped to its config.

OpenTelemetry tracing

End-to-end distributed tracing across all four agents. Exports to Datadog, Grafana Tempo, Jaeger, or any OTLP-compatible backend. Zero overhead when disabled.

LangSmith observability

Every LLM call is traced with prompt, response, token usage, and latency. An automated eval suite covers all three agents — runs on every deploy via GitHub Actions.
